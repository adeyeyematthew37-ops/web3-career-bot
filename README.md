# Web3 Career & Fundraising Intelligence Bot

Premium Telegram bot for Web3 job hunting, project research,
community scouting and fundraising alerts.

## Deploy on Railway
1. Connect this repo to railway.app
2. Add env vars (see .env.example)
3. Deploy -- starts automatically

## Bot Commands
/start, /verify [code], /subscribe, /research [project],
/jobs, /apply, /applications, /update_status, /preferences

## Subscription Code
Default: Pelumi1@
